# Install Software
Before the first practice, you should have the following installed on your PC:
1. Linux. We recommend [Ubuntu][1] or [Kali][2]. If using Windows, you can use 
WSL or [VirtualBox][3].
2. [VirtualBox][3]. Please install VirtualBox, as I'll be distributing a VM
to practice on.
3. [Docker][7]. I will also be using Docker to distribute practice images.
4. [ArchiveWeb.Page][5]. Either Chrome extension or standalone app. Useful
during the competition to save competition webpages in case they get defaced
by red team.
5. [ReplayWeb.Page][6]. Desktop app. Used to view ArchiveWeb.Page archives. We
download the app to avoid sending competition information to third parties.
6. [Wireshark][4]. Wireshark is useful for threat hunting and is an
all-around useful too; to have.
